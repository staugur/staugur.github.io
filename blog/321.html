OpenHub 古诗词接口：随时来一句经典名句

Written by Hiroshi.tao with ♥ on March 23, 2026 in 应用 python 743 words

介绍

OpenHub 提供了一个古诗词名句接口，调用它就能随机得到一句经典诗词名句。数据来源于古诗文网， 收录了 12 大主题、100+ 分类、100+ 古籍来源的句子，从"天生我材必有用"到"人间四月芳菲尽"，覆盖面很广。

它没有复杂的参数，一个链接即可使用，适合给网站、博客、小程序加一点文艺气息。

可以怎么用

  • 随机来一句：直接访问接口，每次返回一句随机名句，适合做"每日一句"。
  • 按条件筛选：想读情诗、想找励志句，或者想指定某位作者，都可以通过链接里的规则实现，例如按作者、主题、分类组合查询。
  • 多种返回格式：默认 JSON 方便程序解析，也有纯文本，还有 SVG 图片格式，可以直接当图片用。

其中 SVG 是最有意思的一种：它生成的是一张可缩放的矢量图，文字可自定义字体和颜色， 大小不会失真。把它放进博客侧边栏、GitHub 仓库的 README、或网页任何位置，都能当一幅漂亮的名句卡片。

快速体验

在浏览器打开下面的地址，就能看到效果（也可在线调试）：

https://hub.saintic.com/openservice/sentence/

想要指定风格，把规则追加在路径后面即可，比如想得到一句"苏轼写的抒情句"，且以图片形式输出：

https://hub.saintic.com/openservice/sentence/sushi.shuqing.svg

SVG 输出时还可以通过参数微调样式，比如切换字体、文字颜色、是否带上原文链接等，让卡片更贴合自己的页面风格。

详细文档请参考：OpenHub 古诗词接口文档

适合什么场景

  • 博客 / 个人网站签名档，自动更新一句诗词
  • README 里的装饰卡片，给开源项目加一点味道
  • 小程序、聊天机器人里的"每日一句"或"诗词接龙"
  • 学习用途：按主题、作者翻读经典句子

接口基于 Flask 构建，带多层缓存加速，并发请求也能保持稳定响应，直接部署在 hub.saintic.com 上，随时可用。

一句话总结：想给页面添点文化感，又不想维护大量文案，这个接口就够了。
