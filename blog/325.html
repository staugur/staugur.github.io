Wallhaven 壁纸：在 hub 上直接取一张随机高清壁纸

Written by Hiroshi.tao with ♥ on October 11, 2026 in 应用 openhub 948 words

介绍

想给桌面或锁屏换张壁纸，又懒得去图库站翻半天？我在 hub.saintic.com 上接了一个 Wallhaven 随机壁纸接口，背后代理的是 wallhaven.cc 的官方搜索接口，但不需要你登录、也不需要去墙外站点，直接一个链接就能拿到一张随机高清图。

它和站点里已有的 Bing 每日壁纸、K站随机图是一家的，都属于「开放服务」，纯 GET 调用，浏览器打开就出图。区别是 Wallhaven 的图库质量高、风格多，找特定主题也方便。

怎么用

最简单的用法，浏览器直接打开：

https://hub.saintic.com/openservice/wallhavenpic

默认会 302 跳转到一张随机壁纸的原图地址，把链接填进桌面/浏览器壁纸插件、或当成图片源就能用。想要程序处理就加 json 参数，返回 JSON（含图片直链、分辨率、分类等字段）。

几个常用的查询参数：

参数说明
q关键词搜索，比如 mountain、minimalism、cyberpunk
category分类筛选：general / anime / people，可逗号或空格分隔，或三位位串如 110
mobile带上则返回移动端竖屏分辨率（适合手机锁屏）
r18带上把纯净度从 sfw 切到 sketchy（不提供 nsfw，本站永不开启）
json带上（或 Accept: application/json）返回 JSON 而非跳转图片

举个例子，想要一张动漫类的随机壁纸：

https://hub.saintic.com/openservice/wallhavenpic?category=anime&json

几个省心的地方

  • 分辨率有保障：桌面端默认落在 1920x1080–3840x2160，移动端 1080x1920–2160x3840；大于 4K 的 8K 大图会被站点这边过滤掉，免得下到一张几十 MB 的图把桌面拖卡。
  • 每次都是新的：排序固定 random，每次回源随机取一张，不会像 toplist 那样老返回榜首那几张，长期挂着当随机壁纸源不会看腻。
  • 访问快：sfw 的图命中后会走 sapic 图床生成国内直链，配合 Redis + 数据库双层缓存，热门请求基本秒回，不用每次都去墙外拉。
  • 干净：默认就是 sfw，r18 最多到 sketchy，不会有突然蹦出来的成人内容。

适合什么场景

  • 浏览器插件 / 桌面软件设成「打开新标签显示随机壁纸」，把这个链接当图片源；
  • 写个小脚本定时拉一张换桌面背景，配合 q + category 定向取某种风格；
  • 手机锁屏想换风格，加个 mobile 直接拿竖屏图；
  • 临时需要一张特定主题的配图（如做 PPT 找张风景底图），q=landscape 随手取。

小结

想要一张高质量、随机、不用翻墙的壁纸，这个接口够轻量也够用：浏览器打开就出图，程序调用就加 json。记不住参数没关系，最常用的就是裸地址和 ?category=xxx&q=xxx 这两种。

挑张喜欢的设上，今天的心情说不定就亮了一点。
