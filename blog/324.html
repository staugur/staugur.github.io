飞书群消息备份：用自建应用把群聊存档

Written by Hiroshi.tao with ♥ on October 2, 2026 in 应用 python 1222 words

介绍

飞书群聊有个麻烦：人退了群就看不到历史消息，时间长了记录还会过期，想翻一句几个月前的对话基本找不回来。

我在 hub.saintic.com 上提供了一个飞书群消息备份服务，思路很简单——你用自己的飞书自建应用把群消息拉下来，文本存库、图片和视频转存图床，之后随时能在网页上检索查看，不依赖飞书客户端，也不怕退群。

数据是按账号和群隔离的：你只能看到自己配置的群，用的是你自己申请的飞书应用凭证，跟其他用户互不干扰。

大概怎么工作

备份基于飞书开放平台的自建应用接口拉取群消息。首次备份会按设定的起点全量回填，之后每次只拉取上次备份时间点之后的新消息（多拉几秒重叠再按消息 ID 去重），时间跨度大的会自动分段，避免触发飞书的频控。

图片、视频这类媒体会转存到 sapic 图床，库里只留图床地址和文件指纹；转存失败或超大会保留飞书的文件 key 备查。发送者姓名在有通讯录权限时一并记下，没有就先存 open_id。

后台默认每 3 小时跑一轮增量备份，不需要手动触发。

怎么用

先在飞书侧准备好

  1. 到飞书开放平台创建一个企业自建应用，拿到 App ID（以 cli_ 开头）和 App Secret；
  2. 给应用开启机器人能力，并申请读取群消息和资源的权限，主要是 im:message.group_msg、im:resource；
  3. 把这个机器人拉进要备份的群，并在群设置里打开「新成员可查看历史消息」——否则它只能读到入群之后的消息；
  4. 想显示发送者真名的话，再申请一个通讯录只读权限 contact:contact.base:readonly，不申请也不影响备份。

更完整的步骤和权限清单见文档：https://docs.saintic.com/hub/feishubak.html。

再到站点配置

  1. 登录 hub.saintic.com，进入顶部导航的「飞书备份」页面；
  2. 填入刚才的 App ID 和 App Secret 并保存（密钥不回显，改 App ID 时留空表示不修改）；
  3. 添加备份群：填写群 ID（以 oc_ 开头），可顺便写个备注名；
  4. 点一下「备份」做首次全量拉取，之后就不用管了，后台会定时增量跑；
  5. 在「备份消息」里选群、按消息类型或关键词检索，点开还能看消息详情和媒体附件。

关于备份开始时间

添加群时可以选一个「备份开始时间」。它的作用只是决定首次全量回填从哪天算起，比如你 2025 年才把机器人拉进群，设成 2025-01-01 就能少跑很多无意义的请求（更早的时间机器人也读不到）。留空则用站点内置的兜底起点 2026-10-01。

这个设置只影响第一次，已经备份过的群不会再从更早的地方重拉。

撤回的消息

飞书里撤回的消息也会被标记保留，在消息详情里能看到「已撤回」标识，不会因为对方撤回就凭空消失。

费用

服务是买断制的：

  • 登录用户默认免费备份 1 个群；
  • 开通买断套餐后提升上限，Pro ￥9.9 可备份 10 个群，Max ￥19.9 可备份 20 个群，一次付费、终身有效。

免费额度对个人玩玩够了，群多再考虑买断。

小结

如果你也想把飞书群里的讨论沉淀下来、以后能检索，又不想自己搭一套服务，到 hub.saintic.com 登录后配置一个飞书自建应用就能用。具体权限和踩坑点还是以文档为准。
